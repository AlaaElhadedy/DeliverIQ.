# DeliverIQ.
الفكرة شركات التوصيل بتخسر فلوس وعملاء بسبب التأخير. المشروع بيجاوب على سؤالين: إيه العوامل اللي بتسبب تأخر الطلبات؟ وهل نقدر نتوقع الطلب المتأخر قبل ما يحصل؟  البيانات حوالي 45,000 طلب توصيل من dataset على Kaggle (Gaurav Malik)، فيها الطقس وكثافة المرور وبيانات المندوب والمواقع وزمن التوصيل
